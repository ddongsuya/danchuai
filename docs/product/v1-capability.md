## 1. 기능 한 줄

의뢰자는 채팅으로 요청서를 만들어 **앱에 가입한 기관 중 직접 고른 곳**에 보내고, 회신을 **도착 순 비교표**로 본 뒤 한 곳을 **선정**한다. 기관은 **받은 요청함**에서 요청을 열어 채팅으로 회신 초안과 견적 금액(코드 계산)을 만들고, 승인한 본문만 의뢰자에게 보낸다. 지금 가짜 자료(demo.ts)로 도는 화면은 모두 실제 DB·API로 바뀐다.

## 3. 지켜야 할 규칙 (고정)

1. 상대에게 나가는 것은 사람이 승인한 정확한 본문만, 한 번만(승인 epoch + 본문 해시, 발송 1회). 에이전트에게 보내기 도구 없음.
2. 기관을 추천·순위 매기지 않는다. 기관 목록은 가나다순, 비교표는 회신 도착 순.
3. 금액은 코드(computeTotals)만 계산. AI가 쓴 금액은 버린다.
4. 선정 전에는 의뢰자 회사명·연락처를 기관 화면과 AI 입력에 넣지 않는다. 선정된 기관에만 공개.
5. 조직(org_id)은 서버 세션에서만. 앱은 서버 API로만 읽고 쓴다(DB 직접 쓰기 없음, 0002의 권한 그대로).
6. 로그에 프롬프트·본문 없음.
7. 화면 문구 해요체, 명사형 라벨, 설명 문구 없음, em dash 없음.

## 4. 상태와 전이

요청(requests.status): `draft` → `sent`(첫 발송 성공) → `selected`(한 곳 선정) 또는 `closed`(의뢰자가 닫음)

받은 기관별(request_recipients.status): `received` → `viewed`(기관이 처음 엶) → `replied`(회신 발송) → `selected` 또는 `not_selected`(다른 곳이 선정됨). 기관이 `declined`(회신 안 함)도 가능.

발송(transport, 앱 안 전달):
- 의뢰자 `request` 초안 발송 = 해당 기관의 request_recipients 행을 만들고 요청을 `sent`로. 결과 `sent`.
- 기관 `reply` 초안 발송 = quotes 행(줄·합계는 서버 계산)과 회신 본문을 저장하고 수신 상태를 `replied`로. 결과 `sent`.
- 선정 = 의뢰자 승인 1회. 선정 기관에 의뢰자 회사명 공개, 나머지 기관 `not_selected`.

## 5. 화면 (휴대폰 390 기준, 한 화면 한 일)

| 화면 | 역할 | 상태 |
|---|---|---|
| 요청함 | 의뢰자 | 기존 시안 있음. 실제 목록·필터(회신 도착/승인 대기/작성 중)·빈 화면 |
| 새 요청 채팅 | 의뢰자 | 있음. 마지막에 **받는 기관 고르기** 추가 |
| 받는 기관 고르기 | 의뢰자 | **새 시안 필요**. 가입 기관 가나다순, 여러 곳 선택, 검색 |
| 요청 상세(진행·회신 비교) | 의뢰자 | 기존 시안 있음. 기관별 상태, 도착 순 비교표 |
| 선정 확인 | 의뢰자 | **새 시안 필요**. 공개되는 정보 표시 후 승인 |
| 받은 요청함 | 기관 | 기존 시안 있음. 실제 목록·빈 화면 |
| 요청 상세·회신 채팅 | 기관 | 기존 시안 있음. 견적 줄은 사람이 넣고 코드가 합계 |
| 선정 결과 | 기관 | **새 시안 필요**. 선정 시 의뢰자 정보, 미선정 표시 |
| 계정 | 공통 | **새 시안 필요**. 이름, 조직, 구성원·초대, 로그아웃 |

모든 화면: 로딩(최종 모양 뼈대), 빈 화면, 오류(문제+다시 시도), 오프라인.

## 6. 서버 API (추가)

| 메서드 | 경로 | 역할 | 내용 |
|---|---|---|---|
| GET | `/v1/labs` | 의뢰자 | 가입 기관 목록(id, 이름), 가나다순 |
| GET | `/v1/requests` | 의뢰자 | 내 요청 목록과 회신 수 |
| GET | `/v1/requests/:id` | 의뢰자 | 요청서, 기관별 상태, 회신(도착 순, 합계는 서버 값) |

| GET | `/v1/lab/requests` | 기관 | 받은 요청 목록(의뢰자 이름 없음) |
| GET | `/v1/lab/requests/:id` | 기관 | 요청서, 내 회신, 선정 결과(선정 시 의뢰자 이름) |
| GET | `/v1/account` | 공통 | 내 이름, 조직, 구성원 |
